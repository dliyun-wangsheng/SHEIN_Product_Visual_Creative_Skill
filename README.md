# SHEIN 商品视觉创作 Skill

本压缩包包含一份可复用的商品视觉工作流说明。

## 文件
- `SKILL.md`：完整 Skill 指令，包含产品识别、真实场景搜索、三参考融合、7–8 张图片规划、逐张生成与强制质检。
- `QA_CHECKLIST.md`：单张图片质检表，可单独复制使用。

## 使用方式
将 `SKILL.md` 作为自定义 GPT、项目指令或支持 Skill 的智能体的核心工作说明。开始新产品时上传产品实物图，并补充已知尺寸、材质、SKU 和安装方式。

注意：该压缩包是可移植的 Skill 指令文件，不会自动安装到 ChatGPT 的系统 Skill 列表中。
