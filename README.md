# SHEIN 商品视觉创作 · ChatGPT 插件

版本：1.0.0。插件标识：`shein-product-visual-creative`。

这是一个 skills-only 插件，保留原有“产品实物图 + 真实使用参考 + 氛围参考 → 套图规划 → 逐张生成与质检”的核心工作流。它使用 ChatGPT 当前对话实际开放的看图、搜索、图像生成和编辑能力，无需自行配置服务器或 API 密钥。

本包是个人整理的商品视觉创作流程，非 SHEIN 官方插件。插件包已准备好供导入和测试；本地生成文件不等于已安装到 ChatGPT 账号，也不等于已经通过平台审核。

## 文件结构

```text
SHEIN_Product_Visual_Creative_Skill/
├── plugin.json
├── README.md
├── assets/
│   └── icon.svg
└── skills/
    └── shein-product-visual-creative/
        ├── SKILL.md
        └── references/
            └── QA_CHECKLIST.md
```

`plugin.json` 是插件入口，使用 Agent Plugins 1.0.0 清单格式。`skills/` 内的技能自动发现；无需再将完整流程复制到插件描述中。`developerName` 的“个人创作工作流”是本地展示标签，正式提交时发布者名称以账号所选的已验证开发者身份为准。本包未编造作者姓名、网站或隐私政策链接。

## 在 ChatGPT 中创建个人插件

如果你的工作区提供 Plugin Creator：

1. 在 ChatGPT 新建对话，输入 `@` 并选择 **Plugin Creator**。
2. 打开本包的 `skills/shein-product-visual-creative/` 目录，附上其中的 `SKILL.md` 和 `references/QA_CHECKLIST.md`。需要图标时再附上插件根目录的 `assets/icon.svg`。
3. 发送下面的创建说明，完成创建后按界面提供的方式安装并在新对话测试。

> 请将附件工作流创建为名为「SHEIN 商品视觉创作」的个人插件。主指令使用 SKILL.md，QA_CHECKLIST.md 作为被主指令引用的配套资料，保持引用可访问。保留产品实拍、真实使用参考、氛围参考的三参考分工，以及套图规划、逐张生成、逐张质检、修改和下一张续做。使用当前对话实际开放的看图、搜索和图像生成能力，不添加外部服务、MCP 服务器或商家后台连接。初始沟通使用中文，图片文案按目标站点和用户要求。缺少材料或工具时按附件规则说明，不能编造执行结果。

插件创建入口和编辑能力取决于账号与工作区权限。如果没有该入口，不能通过在普通聊天里上传 ZIP 自动完成安装；可采用下方开发者上传方式，或由工作区管理员按官方流程导入。

## 使用 ZIP 导入开发者平台

1. 打开 OpenAI 开发者平台的 **Plugins** 页面，选择上传新插件。
2. 选择你自己的开发者身份，上传生成的 `shein-product-visual-creative-1.0.0.zip`。若入口区分插件类型，选择 **Skills only**。
3. 查看 **Metadata & Skills** 校验结果，根据实际提示补充账号资料或调整包内容。
4. 如需公开分发，再按平台流程完成审核并发布；本地结构检查不能代替平台校验、审核或账号权限检查。

ZIP 只有一个插件顶层目录，包含清单、图标、主技能和质检表，不包含 `.git`、本机路径配置、密钥或商品私有图片。当前插件不包含 MCP 配置、生命周期 hooks 或外部服务依赖。

## 开始使用

安装后，新建 ChatGPT 对话，输入 `@`，选择「SHEIN 商品视觉创作」，再上传产品实拍。推荐第一条请求：

> 根据这些产品实拍为美国站制作商品套图。已知尺寸是……，销售数量是……，SKU 是……。先建立事实卡并规划，再制作第一张，每张完成后检查。

常用后续请求：

- “下一张”：沿用当前事实卡和规划，先处理上一张的质检状态。
- “检查这张图”：直接对照产品依据审图，不强制重做套图流程。
- “只给方案，先不生图”：交付规划或提示词。
- “我要换对话继续”：输出可复制的事实卡、规划、进度和纠正摘要。

3:4、7–8 张和主体占比属于创作默认值。需判断当前平台上传要求时，另行核实对应站点和类目的官方依据。插件不自动获得未开放的搜索或生图能力，也不会自动跨对话保存进度。

## 导入后验证

在一个新对话中完成一次小范围测试：上传真实产品图，只要求事实卡和套图规划，确认没有擅自生成；随后要求制作第一张，检查是否实际使用图片工具并对照原图质检；最后发送“下一张”，确认规划和纠正保持一致。实际出图质量及插件在账号内的运行情况需要这一步验证。
