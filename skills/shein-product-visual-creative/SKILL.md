# SHEIN 商品视觉创作 Skill

## ChatGPT 运行约定

本 Skill 随「SHEIN 商品视觉创作」插件使用，依靠当前对话实际开放的看图、搜索和图像生成/编辑能力运行。插件提供工作流，不额外提供这些工具或外部账号连接；不依赖用户电脑上的固定路径、Python、API 密钥或额外服务器。

### 按当前请求进入流程

- 制作新商品套图：执行下方完整流程。
- 只要求规划或提示词：完成事实卡、参考分析和规划，按要求交付，不擅自开始生图。
- 检查已有图片：直接阅读 [单张质检表](references/QA_CHECKLIST.md)，对照用户产品依据逐项检查，不要求先重做搜索和整套规划。
- 修改图片或“下一张”：先恢复当前产品事实卡、已确认规划、上一张质检结果和用户纠正，再执行对应图片任务。

### 图片与工具的实际使用

- 先查看用户上传的图片。用户只给出电脑路径时，先判断当前环境是否有可用的文件访问能力；路径不可访问、附件失效或链接无法打开时，说明缺少哪份材料，请其在当前对话附上必要图片。不得声称已读取无法访问的材料。
- 搜索使用当前对话可用的搜索/浏览能力，不绑定特定工具名。保留选中参考的来源链接和用途；只有实际打开并看过的图片，才能作为视觉证据。
- 生图/改图使用当前对话可用的图像工具，将实际可用的产品图作为图像输入；支持多图参考时，再加入安装和氛围参考并明确各自职责。未能传入的参考只能作为文字描述，不能声称已作为图像输入。
- 工具不可用、参考不可访问或执行失败时，明确说明当前限制，继续完成可执行的事实整理与规划。需要用户选择替代路径时只问一个关键问题；不得编造搜索结果、图片文件或质检结论。
- 每次实际生成后，查看成图并与产品依据对照，再记录质检。如果生图后当前回复自动结束，下一次恢复时先检查上一张，再生成下一张。无法看到成图时记录“待质检”，不能判为通过。
- 默认用中文沟通。图片文案按用户指定语言；未指定时按目标站点选择，美国站用英文，日本站用日文，站点未知时先确认。正文中的汽车案例只适用于车品，其余商品按真实用途选择场景。
- 在本对话维护简短进度：产品事实卡、参考来源、图片规划、已生成图片标识、质检状态、当前序号及纠正约束。用户需要暂停或换对话时，输出可复制的进度摘要；不承诺自动跨对话记忆。

## 1. 目标

为 SHEIN 美国站、日本站等跨境电商商品制作一套真实、统一、有质感、适合转化的商品图片。

核心原则：

**真实产品负责还原，真实同款场景负责安装逻辑，高级场景负责氛围，逐张质检负责把关。**

不要一看到产品就直接凭空生成场景。先研究，再规划，再生成，再检查。

## 2. 工作总流程

每个新产品严格按以下顺序执行：

1. 接收并识别产品实物图。
2. 建立产品事实卡，锁定不可改变的产品信息。
3. 搜索同款或高度相似产品的真实场景图。
4. 搜索符合产品使用场景的高级质感场景图。
5. 分别提取安装参考和氛围参考，形成融合方案。
6. 规划 7–8 张商品图，明确每张图的任务与差异。
7. 逐张生成图片。
8. **每生成一张，立即执行质检；未通过则修正并重生，不直接进入下一张。**
9. 完成整套图片后做统一性复核。

除非用户明确要求跳过，不得跳过搜索、规划或质检步骤。

## 3. 第一步：产品识别与产品事实卡

从用户提供的实物图、尺寸图、侧面图、安装配件图中识别：

- 产品名称和用途
- 外形轮廓、结构、开口、边缘、连接件
- 主色、辅色、图案、纹理
- 材质及表面质感
- 长、宽、高、直径等尺寸
- 包装数量、SKU、配件
- 安装方式、安装位置、朝向
- 已确认的限制和用户纠正过的问题

输出简洁的「产品事实卡」。

每项标记“已确认 / 视觉推断 / 未知”并注明附件或用户说明来源。照片只能支持可见特征，不能单凭纹理确认材质成分、包装件数或 SKU；未知规格不得写成确定的尺寸、功能或卖点。

### 产品锁定规则

- 实物图是外观、颜色、材质、图案、比例和细节的最高优先级依据。
- 不擅自改款，不添加不存在的配件，不删除真实结构。
- 不把平面产品变成立体玩偶，不把柔软材质生成成硬塑料，反之亦然。
- 不镜像产品图案，不随意改变图案方向或重复密度。
- 尺寸必须按真实尺寸表达。场景中产品的视觉占比应符合物理常识。
- 如果关键结构或尺寸不清楚，先问一个最关键的问题，不要猜。

## 4. 第二步：搜索同款产品真实场景图

### 搜索目的

同款产品图的首要价值不是借用它的审美，而是确认产品如何真实使用：

- 产品实际安装在哪里
- 如何固定、绑扎、卡扣或悬挂
- 产品朝向和正反面
- 产品与座椅、头枕、后视镜、方向盘等物体的相对位置
- 真实尺寸比例
- 用户如何拿取、使用或操作
- 适合展示的镜头角度

### 搜索来源

优先查找可访问的真实图片和页面，例如：

- Google/Bing 图片搜索
- Pinterest
- Unsplash
- Shutterstock
- Adobe Stock
- 品牌或零售商公开商品页
- 用户提供的视频截图、实拍图、安装图

不同来源的图片可能有授权限制。参考图用于分析和创作，不代表可以直接复制或商用。需要商用原图时应确认授权。

### 搜索策略

使用“产品类型 + 安装位置 + 使用动作 + 视角”组合搜索，而不只搜索产品名称。

例如，座椅背挂式纸巾盒可搜索：
- car tissue holder attached to front seat headrest
- rear seat view of front passenger seat tissue holder
- car seat back tissue dispenser in use
- close-up hand pulling tissue from car seat organizer

### 同款参考筛选标准

优先级从高到低：

1. 安装结构与用户产品相同
2. 安装位置与使用方向相同
3. 镜头角度能看清关键结构
4. 尺寸比例可信
5. 画面清晰、光线自然

如果找不到完全同款，使用“结构相似、安装逻辑相同”的参考，并明确标注哪些部分只是推断。

## 5. 第三步：搜索高级场景参考图

### 搜索目的

高级场景图负责提升画面氛围、材质表现和商业摄影质感，不负责决定产品安装方式。

先根据产品用途选择场景，再搜索场景，不要反过来为了套用某张豪华图片而改变产品使用逻辑。

### 可提取的场景维度

- 车型气质：现代豪华轿车、运动型汽车、家庭 SUV、简洁电动车等
- 内饰材质：真皮、麂皮、木纹、金属饰条、钢琴烤漆
- 色彩：黑灰、棕黑、米棕、冷灰、黑红等
- 光线：自然窗光、柔和侧光、阴天漫射光、傍晚暖光
- 构图：前排全景、后排向前、侧后方斜拍、产品近景、微距
- 景深：主体清晰，背景适度虚化
- 情绪：干净、克制、现代、舒适、精致

### 场景筛选标准

- 画面符合目标市场审美和产品定位
- 有真实空间关系，能容纳产品
- 光线方向和产品使用环境合理
- 不过度装饰，不抢产品主体
- 不包含明显品牌标识、车标、车牌或侵权元素；必要时隐藏或避开
- 不因“豪华感”而选用与产品不匹配的环境

## 6. 第四步：三参考融合

每次生成前，明确三类参考各自负责什么：

| 参考类型 | 负责锁定 | 不负责 |
|---|---|---|
| A. 产品实物图 | 外观、颜色、材质、图案、比例、结构 | 场景氛围 |
| B. 同款真实场景图 | 安装位置、固定方式、朝向、使用动作、真实比例、镜头视角 | 产品外观改款 |
| C. 高级场景图 | 车内环境、光线、色彩、质感、构图、景深 | 安装结构和产品尺寸 |

### 融合原则

- 先以 A 锁定产品，再以 B 建立正确安装和视角，最后以 C 提升场景表现。
- 不要把三张参考图的元素机械拼接。
- 只提取场景图的摄影语言，不复制其品牌、人物身份、标识或受保护的独特设计。
- 产品必须自然落在场景空间中，接触关系、遮挡关系、透视和阴影合理。
- 若参考图之间存在冲突，优先级为：用户明确要求 > 产品实物结构 > 同款安装证据 > 场景审美参考。

## 7. 第五步：规划 7–8 张商品图

默认建议 8 张；按产品特性调整，不为凑数制造重复图片。

1. **主图 / Hero**：第一眼识别产品和核心用途，产品清楚、场景有吸引力。
2. **第二场景图**：换视角或空间，展示实际安装状态，避免与主图重复。
3. **使用体验图**：真实手部或人物动作展示使用过程；动作必须符合人体工学和产品功能。
4. **安装结构图**：展示绑带、卡扣、挂钩、夹具、接口等真实安装逻辑。
5. **细节图**：纹理、缝线、边缘、连接件、印刷、材质等。
6. **侧面 / 多角度图**：呈现厚度、侧面结构、背面或空间关系。
7. **尺寸图 / 适配图**：准确标注尺寸和单位；不臆测适配范围。
8. **白底 SKU 图 / 多色图**：清楚呈现实际销售内容、颜色和数量。

### 每张图必须先写清楚

- 图片序号与任务
- 镜头位置和方向
- 产品在画面中的位置与占比
- 产品安装方式和朝向
- 场景、光线、色调
- 是否需要手部/人物
- 是否需要文案及文案语言
- 该图与其他图片的差异点

## 8. 第六步：逐张生成规则

- 默认采用 3:4 竖版，除非用户另有要求。
- 3:4、张数和主体占比是创作默认值，不代表已经核实当前 SHEIN 站点或类目的上传要求；用户要求平台合规核验时，另行查证相应官方依据并记录来源与日期。
- 写实商业摄影，清晰、自然、年轻、干净、有质感。
- 产品通常占画面约 55%–75%；根据产品大小和场景任务调整，不机械套用。
- 产品纹理、图案、轮廓和关键结构必须清晰。
- 手部动作自然，不能悬浮、穿透、错指或与产品接触错误。
- 产品与座椅、玻璃、后视镜、出风口等接触关系必须可信。
- 车内场景保持合理透视和统一光线。
- 默认隐藏车标、车牌、无关品牌 Logo 和水印。
- 不随意添加文字；如需文字，按已确定的目标语言使用简洁、准确的文案。
- 不为了追求“高级”而把产品放大到不符合真实尺寸。

## 9. 第七步：每张图片生成后的强制质检

**这是强制步骤。每生成一张，必须检查后才能交付或继续下一张。**

执行时使用 [单张质检表](references/QA_CHECKLIST.md) 记录结果。不可见或缺少依据的项目标记“无法判断”，与当前图片任务无关的项目标记“不适用”；无法判断的关键结构、规格或销售数量不得计为通过。

### A. 产品还原度

- [ ] 外形轮廓是否一致
- [ ] 颜色、图案、纹理是否一致
- [ ] 材质表现是否合理
- [ ] 开口、缝线、边缘、扣件等细节是否正确
- [ ] 是否出现变形、增件、缺件、镜像或错误图案

### B. 尺寸与比例

- [ ] 场景中的视觉大小是否符合真实尺寸
- [ ] 产品与座椅、头枕、后视镜、手掌等参照物比例是否合理
- [ ] 是否过大、过小或比例失真
- [ ] 是否遵循用户给出的长宽高

### C. 安装与使用逻辑

- [ ] 安装位置是否正确
- [ ] 绑带/卡扣/挂钩是否按真实方式固定
- [ ] 产品朝向是否正确
- [ ] 是否出现悬浮、穿透、错误受力或不可能的连接
- [ ] 使用动作是否符合真实操作

### D. 场景与摄影质量

- [ ] 光线方向、色温、阴影是否一致
- [ ] 透视、景深、遮挡关系是否自然
- [ ] 背景是否符合产品定位
- [ ] 产品是否突出，背景是否喧宾夺主
- [ ] 是否存在 AI 常见瑕疵、重复结构或不合理细节

### E. SHEIN 商业可用性

- [ ] 是否符合本次约定的画幅比例（默认 3:4）
- [ ] 产品是否足够清晰
- [ ] 画面是否简洁、有吸引力
- [ ] 文案是否准确、无拼写错误
- [ ] 是否有不必要的 Logo、车标、车牌、水印
- [ ] 是否真实表达商品，不误导消费者

### 质检结果

每张图给出以下一种结论：

- **通过**：可进入下一张。
- **有条件通过**：仅限不影响商品真实性和购买判断的小问题，列明处理方式及是否需要复检；未修正版本不作为最终合格图交付。
- **不通过**：明确指出具体错误，生成修正版后重新质检。
- **待确认 / 待质检**：关键依据不足或无法查看成图，注明待补材料，不冒充通过。

不要只说“更高级了”“看起来不错”。必须指出具体证据，例如“挂件相对后视镜过大”“卡扣跑到侧面”“绑带没有绕过正确位置”。

### 不合格时的修正方式

1. 只修改不合格项，尽量保留已正确的构图和产品细节。
2. 把错误写成明确的负面约束。
3. 重生后重新执行完整质检。
4. 未通过前不进入下一张。
5. 同一关键错误连续两次修正仍存在时，先重新检查产品依据和参考，改用局部编辑、补充安装实拍或调整镜头；说明需要的材料或选择，避免无限重生。

## 10. 整套图片最终复核

完成 7–8 张后统一检查：

- 产品外观是否从头到尾一致
- 同一产品的尺寸比例是否稳定
- 安装方式是否前后一致
- 颜色、材质、场景色调是否统一
- 各张视角是否有变化，是否避免重复
- 每张图是否承担不同销售任务
- 是否有误导性卖点或未经确认的功能
- 是否有不合格图片混入最终套图

最终交付时提供：
1. 图片顺序
2. 每张图的用途
3. 质检结果
4. 尚存风险或需要实拍确认的点

## 11. 与用户协作的默认规则

- 用户说“下一张”：按已确认的套图规划生成下一张，不重新发明整套方案。
- 用户说“检查图片”：调用本 Skill 的质检清单逐项检查，不能只给笼统评价。
- 用户指出错误：将该纠正视为当前产品后续图片的硬约束。
- 用户说“太假”：优先排查安装逻辑、接触关系、产品比例、光影和透视，不只是换滤镜。
- 用户提供新的实拍图、侧面图、安装图：更新产品事实卡，并以新证据修正后续生成。
- 不确定下一张的任务时，先简短说明建议的下一张内容；必要时只问一个关键问题。

## 12. 测试案例：圣诞老人汽车后视镜挂件

已确认的产品事实：
- 产品类型：汽车内后视镜挂件
- 主体：圣诞老人毛绒装饰
- 挂绳：红色编织绳，带白色缠绕段
- 连接件：浅色圆环/扣件
- 用户提供尺寸：整体长度约 20 cm，宽度约 6.5 cm

特别质检约束：
- 不能把挂件生成得像大型毛绒玩偶。
- 20 cm 长、6.5 cm 宽的挂件在车内应呈现为小型装饰，需通过后视镜和车内参照物校准。
- 保留真实红色挂绳、白色缠绕段、连接环和圣诞老人主体。
- 挂件自然垂挂，不能悬空脱离后视镜连接处。
- 每张图生成后都要先检查尺寸感、连接结构、主体形状和毛绒质感，再继续下一张。

此案例只作为特定产品的测试示例，不应把圣诞元素带入其他产品。
